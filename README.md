## Research & Featured Projects

### [Hierarchical Commodity Portfolio Construction](https://github.com/CsVazquezz/Quant_CaseStudy)
Systematic two-stage backtesting engine across 10 commodity sectors over 162 weekly periods
- **Optimization:** SLSQP min-variance with KKT optimality, Ledoit-Wolf shrinkage for covariance regularization
- **Performance:** 4.02 Adjusted Sharpe (Lo 2002), 2.1 Calmar Ratio, max 7.7% annual volatility

### [OrbitGrow: Martian Plant Health Monitoring](https://github.com/CsVazquezz/OrbitGrow_StartHack)
Real-time computer vision system for crop health monitoring in Martian greenhouses — **Top 5 Finalist out of 30 teams, St. Gallen, Switzerland**
- **Tech Stack:** AWS SageMaker, computer vision, multi-modal data pipeline
- **Features:** Autonomous stress detection, spectral imagery processing, nutrient deficiency diagnosis

### [AquaHub: Predictive Drought Modeling & Crowdsourcing](https://github.com/CsVazquezz/AquaHub)
Predictive ML model for drought detection in CDMX, covering 17.7M residents
- **Data:** 960+ training samples, 5-day sliding window architecture
- **Performance:** 70–85% accuracy in preliminary drought event detection
- **Validation:** Crowdsourced reports cross-referenced against meteorological norms

### [Bloomly: Global Bloom Detection System](https://github.com/CsVazquezz/-Bloomly-Global-Algal-Bloom-Detection) 
LightGBM-based predictive model for harmful algal bloom detection
- **Tech Stack:** LightGBM, Flask, Three.js, Google Earth Engine, NASA POWER API
- **Features:** 44 ecological indicators, 3D spatial visualization, temporal cross-validation (AUC/F1)

### [Automated Academic Scheduling System](https://github.com/CsVazquezz/-Automated-Academic-Scheduling-System)
Constraint satisfaction algorithm for optimized course scheduling
- **Tech Stack:** PostgreSQL, Node.js, React, TypeScript
- **Impact:** Serving 150+ users with real-time editing capabilities
- **Optimization:** 40% improvement in query performance through indexing strategies

### [Multi-Agent 3D Simulation](https://github.com/CsVazquezz/-Multi-Agent-3D-Simulation)
Strategic decision-making simulation with autonomous agents
- **Tech Stack:** Python (Mesa), Unity, C#
- **Methods:** Monte Carlo sampling, pathfinding heuristics, policy learning
- **Focus:** Emergent equilibrium analysis in constrained environments
