## Research & Featured Projects

### [Hierarchical Commodity Portfolio Construction](https://github.com/CsVazquezz/Quant_CaseStudy)
Walk-forward backtesting engine allocating across 10 commodity-sector strategies, tested over 110 out-of-sample weeks
- **Method:** 52-week estimation window, 4-week rebalance, Ledoit-Wolf covariance shrinkage, SLSQP min-variance and max-Sharpe with 40% weight caps
- **Performance (OOS, min-variance):** Sharpe 1.9 (t ≈ 2.7), 6.2% annual volatility, −3.3% max drawdown, 10% annual turnover

### [OrbitGrow: Martian Plant Health Monitoring](https://github.com/CsVazquezz/OrbitGrow_StartHack)
Computer vision system for crop health monitoring in Martian greenhouses — **Top 5 of 30 teams, Syngenta Challenge @ START Hack, St. Gallen, Switzerland**
- **Tech Stack:** AWS SageMaker, computer vision, multi-modal data pipeline
- **Features:** Stress detection and nutrient-deficiency diagnosis from environmental telemetry and spectral imagery

### [Bloomly: Global Bloom Detection System](https://github.com/CsVazquezz/-Bloomly-Global-Algal-Bloom-Detection)
LightGBM model for harmful algal bloom detection — NASA Space Apps Challenge
- **Tech Stack:** LightGBM, Flask, Three.js, Google Earth Engine, NASA POWER API
- **Method:** Feature selection across 44 ecological indicators, evaluated with AUC/F1 under temporal cross-validation

### [AquaHub: Drought Monitoring & Crowdsourcing](https://github.com/CsVazquezz/AquaHub)
Drought monitoring for Mexico City, started as a predictive model and pivoted to crowdsourced reporting to fill data gaps
- **Data:** Weather data plus crowdsourced reports validated against historical meteorological norms
- **Modeling:** 5-day sliding-window drought classifier trained on 960+ samples (preliminary)

### [Automated Academic Scheduling System](https://github.com/CsVazquezz/-Automated-Academic-Scheduling-System)
Constraint-satisfaction course scheduler for a design school, serving 150+ users
- **Tech Stack:** PostgreSQL, Node.js, React, TypeScript
- **Method:** Backtracking search with constraint propagation; database indexing to speed up constraint queries

### [Multi-Agent 3D Simulation](https://github.com/CsVazquezz/-Multi-Agent-3D-Simulation)
Simulation of autonomous agents making strategic decisions in a constrained environment
- **Tech Stack:** Python (Mesa), Unity, C#
- **Methods:** Monte Carlo sampling, pathfinding heuristics, reward-based agent policies
